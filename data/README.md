# 数据目录

把原始表格放进这个目录即可（支持 `.xlsx` / `.xlsm` / `.xls`）。

多个文件时优先取 `.xlsx`。也可以改 `config.json` 的 `输入文件` 指定具体路径，
或用 `--input` 参数临时指定：

```bash
python scripts/build_all.py --input "D:/某个报表.xls"
```

## 本项目的原始数据

数据集含客户真实姓名，因此**不纳入版本库**。若需复现本仓库中的分析结果，
请自备一份同结构的三表数据：

| 工作表 | 作用 | 必需字段 |
| --- | --- | --- |
| 订单 | 订单明细 | 订单 ID、客户 ID、产品 ID、行 ID、订单日期、发货日期、销售额、数量、利润、折扣、类别、子类别、细分、邮寄方式、地区 |
| 退货 | 退货记录（**先按整行去重再使用**） | 订单 ID |
| 销售人员 | 地区 → 地区经理 | 地区、地区经理 |

## 表名或列名不一样怎么办

不必改代码，改 `config.json`：

```json
{
  "表名":   { "订单": "销售明细", "退货": "退款记录", "销售人员": "区域负责人" },
  "字段映射": { "订单 ID": "order_id", "销售额": "sales", "利润": "profit" }
}
```

拿不准怎么填，先跑一次结构体检，它会直接列出源文件实际有哪些表和列：

```bash
python scripts/convert_xls.py --input "你的文件.xls"
```
